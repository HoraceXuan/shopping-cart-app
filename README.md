# Shopping Cart Website

## Project Overview

This project is a shopping cart website developed for the Internet Programming assignment.

Main features:
- User registration
- User login
- Protected routes
- Product display
- Shopping cart
- Order history
- MySQL database connection

---

## Technologies Used

- React
- Vite
- Node.js
- Express.js
- MySQL
